# AAE + AEIS foundation

Opt-in live ensemble coordinator with a common immutable observation snapshot, typed individual roles, team hostility, target reservations, formation slots, bounded event memory, native skill execution and independent objective witnesses. Existing two-character runtime remains the default.

Supported objectives: reach, escort a same-team reach leader, intercept an enemy (completion requires native hit, not capture). No LLM in physics loop. First benchmark: two teams, ten actors, zero authored actions, ten distinct native completion witnesses. Target allocation test for five versus five, not yet a full ten-actor combat film.

Not yet implemented: arbitrary story compilation, dynamic social relationship changes, shared prop reservations, advanced rescue objectives, collective tactics beyond assignment and formation, learned motion, AI LOD, cinematic quality benchmarking. Do not describe as production-ready until native regression and artistic review.
