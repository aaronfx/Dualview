# Ensemble milestone: rescue, acting, live skills, cinematic rehearsal

New capabilities:
- assist objective: native settled-fall observation; pair hand offer and assisted stand; native grip plus stood_up with matching helper as witness
- optional event-driven relief and celebration clips, with emotional state derived from hurt, hit and recovery
- shared registry for ActionType vocabulary, existing native event metadata and four explicit live dispatch adapters (pick_up, offer_hand, get_up, act)
- event-derived camera cuts, comparison of unaltered static and event coverage, unchanged Inspector gate, final native render QA
- actual three-actor rescue benchmark; ten-actor evacuation and combat regression tests

Limitations: no claim that all native skills have live adapters or that all genres, large casts, social dynamics and cinematic art are solved. Rescue is floor-based assisted recovery, not arbitrary structural rescue. The first five-versus-five benchmark tests several native contacts, not a full professional battle. Runtime affect is a bounded heuristic, not learned motion. Live LLM compilation remains unverified; CI explicitly disables paid calls. Do not merge without new regression evidence. Existing APEX branch untouched.
