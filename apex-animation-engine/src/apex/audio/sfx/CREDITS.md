# Sound-effect credits

APEX's sound director layers these recorded samples with its own synthesised sounds. Every file can be used in commercial videos.

- **CC0 1.0 (public domain):** no attribution is required. It is given here anyway.
- **The wet-towel pack** is also published as CC0 on OpenGameArt. Its own notice adds MIT, zlib and new-BSD licences; that notice is kept in `licenses/` as those licences ask.

The files were downloaded from OpenGameArt.org on 2026-11-21 and the licence shown on each page was checked. Only a curated subset is included. File names are unchanged.
