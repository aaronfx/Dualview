# Jesus Shorts – batch 1 (Problem → Helping → Reward)

Formula (copied from the channel's winning Short): Jesus is NAMED in the hook as a poor stranger → people refuse → a child or poor person helps despite an unanswered prayer → his footprints glow → the prayer is answered → "They had welcomed their Savior." Visual style = Past Survivor / Ice Age doodle-explainer painted illustration, vertical 9:16 (1080×1920), yellow outlined keyword label on each scene, sentence captions, Ken Burns motion, ~2.5 s per image (Short 1 is already reworked to 18 scenes; Shorts 2-5 are still 11-12 scenes and get reworked next). Narrator: same ElevenLabs voice as the winning Short (Mark).

These are **original parable-style stories**, not Gospel accounts. They are inspired by Matthew 25:35-40 ("I was a stranger and you took me in") and Hebrews 13:2; the YouTube description must say so, so viewers aren't told these events are in the Bible.

## Workflow
1. Paste the master prompt in ChatGPT, make the character sheet.
2. Generate one short's images (12–13) in that chat, name them 01, 02….
3. Make the narration in ElevenLabs (Ron, same voice) from that short's narration file.
4. Send me mp3 + the images; I build the 1080×1920 video with Ken Burns, yellow keyword labels and captions.
